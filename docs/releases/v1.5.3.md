# Browser Relay 1.5.3

Fix activity indicators disappearing before short reads, clicks and scrolls have
shown a full animation cycle. After an operation completes, the page glow and
favicon animation now remain active for four seconds instead of 600 ms.
Another operation renews that interval without restarting the animation.

Cancellation, disconnect and tab closure keep their immediate cleanup behavior.
Ordinary tabs, connection setup and session heartbeats still do not start the
effect. The glow's colors, movement and shape are unchanged.

The regression test uses completed short reads with gaps between calls. Live
Chrome verification on X covered eight reads and four scrolls taking 47–129 ms
each: the indicator stayed active between calls, the favicon animated, and the
effect cleared after the final operation's four-second interval.

## Upgrade

```bash
npm install -g @linsoai/browser-relay@1.5.3
browser-relay restart
browser-relay doctor
```

If doctor still reports an older running Chrome executor, reload the existing
unpacked Browser Relay extension in Chrome. The extension ZIP is also attached
to this release.
