# Browser Relay 1.5.1

`browser-relay skill` and `browser-relay skill command` now print an installation command for all agents using `--agent "*"`. The wildcard is quoted for safe copying into a shell. Doctor guidance and the English/Chinese documentation use the same default; explicit agent selection remains available.

These commands print installation instructions. Run the printed command to install the Skill.

Upgrade:

```bash
npm install -g @linsoai/browser-relay@1.5.1
browser-relay skill
```
